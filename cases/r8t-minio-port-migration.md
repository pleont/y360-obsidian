# MinIO — миграция порта 9000 → 443

## Проблема

MinIO после переезда на порт 443 оставил устаревшие ссылки `:9000` в конфигах продуктов.

## Симптом

Forms `SignatureDoesNotMatch` — temporal-worker не мог создавать миниатюры через старый порт.

## Исправление

MinIO перенесён на порт 443. temporal-worker создаёт все 7 размеров миниатюр с кодом 200 на :443.

## Осталось

13 ресурсов в 6 namespace несут старый endpoint `:9000`. Требуется перекат установки для обновления конфигов продуктов.

PVC forms-uploader проверен fsck на r8t-k8s-04, здоров.

## Проверка

```bash
kubectl get configmap,secret -A -o yaml | grep ':9000'
```
